# 视频上传说明

## 📁 视频保存位置

视频会保存到本地，具体位置取决于你启动服务器的位置：

### 如果从 `video_object_removal_web/` 目录启动服务器：

**上传的视频保存在：**
```
D:\XUEXI\ProPainter\video_object_removal_web\uploads\
```

**处理后的视频保存在：**
```
D:\XUEXI\ProPainter\video_object_removal_web\outputs\
```

### 启动服务器时会显示实际路径

启动服务器时，终端会显示：
```
============================================================
视频物体删除 Web 应用
============================================================
模块状态: 可用
上传目录: D:\XUEXI\ProPainter\video_object_removal_web\uploads
输出目录: D:\XUEXI\ProPainter\video_object_removal_web\outputs
============================================================
```

**请查看启动时的输出，确认实际的上传目录路径。**

## 🔍 如果一直显示"正在上传视频..."

### 检查步骤：

1. **打开浏览器控制台（按F12）**
   - 切换到"Network"（网络）标签
   - 点击"开始处理"按钮
   - 查看是否有 `/api/upload` 请求
   - 如果请求失败，会显示红色，点击查看详情

2. **查看服务器终端输出**
   - 启动服务器时应该能看到上传日志
   - 如果文件太大，上传可能需要较长时间

3. **检查上传目录**
   - 查看 `video_object_removal_web\uploads\` 目录
   - 看是否有文件正在写入（文件大小会增长）

### 常见问题：

**问题1：文件太大**
- 视频文件很大（几百MB），上传需要时间
- 请耐心等待，大文件上传可能需要几分钟

**问题2：浏览器错误**
- 按F12打开控制台，查看是否有错误信息
- 常见错误：网络错误、文件格式不支持等

**问题3：服务器没有响应**
- 检查服务器是否正在运行
- 查看服务器终端是否有错误信息

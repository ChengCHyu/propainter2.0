🎬 视频物体删除工具

上传视频，框选要删除的物体，自动生成掩码

使用说明：

  1. 点击"选择视频"按钮上传视频文件
  2. 视频加载后，点击播放按钮开始播放
  3. 暂停到想要框选物体的帧
  4. 在画面上按住鼠标左键拖拽，框选要删除的物体（可框选多个）
  5. 点击"开始处理"按钮，系统会自动生成掩码并删除物体
  6. 处理完成后，可以在页面中预览和下载处理后的视频

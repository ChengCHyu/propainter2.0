# 独立使用说明

## ✅ 项目已完全独立

本项目现在**完全不依赖父目录的任何文件**，所有依赖都已包含在 `src/dependencies/` 目录中。

## 📁 最终项目结构

```
video_object_removal/
├── src/
│   ├── member_a/          # 成员A：文本定位模块
│   ├── member_b/          # 成员B：分割与追踪模块
│   ├── tools/             # 工具脚本
│   ├── dependencies/      # 所有依赖（完全独立）
│   │   ├── tools/         # Track-Anything工具
│   │   ├── tracker/       # CUTIE追踪器
│   │   └── utils.py       # 工具函数
│   └── pipeline_end_to_end.py
│
├── examples/              # 示例脚本
├── requirements.txt
└── README.md
```

## 🚀 使用方法

### 在项目目录下运行

```bash
cd video_object_removal

# 方式1：命令行
python -m src.member_b.main --video path/to/video --bbox "[[x1,y1,x2,y2]]"

# 方式2：Python代码
python examples/test_member_b.py
```

### 在其他目录运行

```python
import sys
import os

# 添加项目路径
sys.path.insert(0, 'path/to/video_object_removal/src')

from member_b.segment_track import MemberBTrackAnything

module = MemberBTrackAnything()
# 使用模块...
```

## ✅ 验证独立性

所有导入现在都指向 `src/dependencies/`：
- `tools.interact_tools` → `src/dependencies/tools/interact_tools`
- `tracker.base_tracker` → `src/dependencies/tracker/base_tracker`
- `dependencies.utils` → `src/dependencies/utils.py`

**不依赖**：
- ❌ 父目录的 `web-demos/`
- ❌ 父目录的 `model/`
- ❌ 父目录的 `utils/`
- ❌ 父目录的任何文件

## 📝 注意事项

1. **模型文件**：模型文件（SAM、CUTIE）会自动下载到 `weights/` 目录
2. **依赖安装**：需要安装 `requirements.txt` 中的依赖
3. **完全独立**：可以复制整个 `video_object_removal/` 目录到任何地方使用

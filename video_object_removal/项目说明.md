## 🔗 与ProPainter的关系

本项目依赖ProPainter项目的以下部分：
- `web-demos/hugging_face/` - Track-Anything工具模块
- `inference_propainter.py` - ProPainter推理脚本
- `model/` - ProPainter模型代码

本项目独立的部分：
- `src/member_a/` - 文本定位模块
- `src/member_b/` - 分割与追踪模块
- `src/tools/` - 工具脚本

## 📦 部署

如果需要将本项目作为独立模块使用，只需：

1. 复制 `video_object_removal/` 目录
2. 确保ProPainter项目的依赖部分存在
3. 安装依赖：`pip install -r requirements.txt`
4. 下载模型文件

# 简单说明

## 1️⃣ 边界框的四个数字是什么意思？

### 📐 图像坐标系统

```
(0,0) ──────────────→ X轴（向右）
  │
  │     ┌─────────┐
  │     │         │
  │     │  物体   │  ← 这是你要删除的物体
  │     │         │
  │     └─────────┘
  │
  ↓
 Y轴（向下）
```

### 🎯 四个数字的含义

```python
bbox = [x1, y1, x2, y2]
#        ↑    ↑    ↑    ↑
#      左上角X  左上角Y  右下角X  右下角Y
```

**具体解释：**
- **x1**: 物体左边（Left）的X坐标
- **y1**: 物体上边（Top）的Y坐标  
- **x2**: 物体右边（Right）的X坐标
- **y2**: 物体下边（Bottom）的Y坐标

### 📝 实际例子

```python
# 示例：一个100x100像素的物体，位置在图像的(100, 100)处
bbox = [100, 100, 200, 200]

# 解释：
# - 物体左上角在 (100, 100)
# - 物体右下角在 (200, 200)
# - 物体宽度 = 200 - 100 = 100像素
# - 物体高度 = 200 - 100 = 100像素
```

**可视化：**
```
图像 (640x480像素)
┌─────────────────────────────────────┐
│                                     │
│     (100,100) ─────── (200,100)    │
│         │                │         │
│         │     物体        │         │
│         │                │         │
│     (100,200) ─────── (200,200)    │
│                                     │
└─────────────────────────────────────┘
```

### 🔍 如何找到这些数字？

**方法1：查看图像**
- 打开视频第一帧图像
- 用图像查看工具查看物体位置
- 记录左上角和右下角的坐标

**方法2：使用成员A的输出**
- 成员A（GroundingDINO）会自动检测物体
- 直接使用成员A输出的边界框即可

**方法3：手动测试**
```python
# 先随便给一个坐标测试
bbox = [150, 150, 250, 250]

# 运行看看效果，如果不准确再调整
```

## 2️⃣ PowerShell错误：No module named 'cv2'

### ❌ 错误原因

缺少 `opencv-python` 模块（cv2就是opencv-python）

### ✅ 解决方法

**最简单的方法：**

```powershell
# 安装opencv-python
pip install opencv-python

# 或者安装所有依赖
pip install -r requirements.txt
```

**如果pip很慢，使用国内镜像：**

```powershell
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple opencv-python
```

### 🔍 验证安装

安装后测试：

```powershell
python -c "import cv2; print('✓ OpenCV安装成功！版本:', cv2.__version__)"
```

### 📦 完整依赖安装

成员B需要的所有依赖：

```powershell
pip install opencv-python numpy pillow imageio imageio-ffmpeg tqdm
pip install torch torchvision
pip install segment-anything
```

或者直接：

```powershell
pip install -r requirements.txt
```

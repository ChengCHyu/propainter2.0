# 多物体删除功能说明

## ✅ 支持同时删除多个物体

**系统完全支持同时删除多个物体！** 你可以一次性删除视频中的多个不同物体。

## 🎯 使用方法

### 方法1：文本输入（自动检测多个物体）

使用文本输入时，GroundingDINO 会自动检测所有匹配的物体：

```python
# 示例：删除视频中的多个物体
text_prompt = "car . person . tree"  # 用点号分隔多个物体类型
```

**前端使用：**
1. 选择"文本输入"模式
2. 输入描述，例如："删除视频中的汽车和人物"
3. 点击"生成边界框"
4. 系统会自动检测并框选所有匹配的物体

### 方法2：手动框选多个物体

**前端使用：**
1. 选择"手动框选"模式
2. 在视频上拖拽框选第一个物体
3. 继续框选第二个、第三个...物体
4. 所有边界框会显示在列表中
5. 点击"开始处理"

**代码使用：**
```python
from member_b.member_b_api import MemberBAPI

api = MemberBAPI()

# 多个边界框
bboxes = [
    [100, 100, 200, 200],  # 物体1：左上角区域
    [300, 300, 400, 400],  # 物体2：右下角区域
    [500, 150, 600, 250],  # 物体3：中间区域
]

result = api.process(
    video_path='video.mp4',
    bboxes=bboxes,  # 传入多个边界框
    output_path='output'
)
```

### 方法3：组合使用

1. 先用文本输入快速定位主要物体
2. 切换到手动框选模式
3. 添加或调整边界框
4. 开始处理

## 📝 边界框格式

多个边界框使用列表格式：

```python
bboxes = [
    [x1, y1, x2, y2],  # 物体1
    [x1, y1, x2, y2],  # 物体2
    [x1, y1, x2, y2],  # 物体3
    # ... 可以添加更多
]
```

每个边界框格式：`[左上角x, 左上角y, 右下角x, 右下角y]`

## 🔍 工作原理

1. **生成掩码**：系统会为每个边界框生成独立的掩码
2. **合并掩码**：所有物体的掩码会合并成一个完整的掩码
3. **统一删除**：ProPainter 会一次性删除所有标记的物体

## ⚠️ 注意事项

1. **性能影响**：
   - 删除多个物体会增加处理时间
   - 物体越多，处理时间越长

2. **显存占用**：
   - 多个物体会增加显存占用
   - 如果显存不足，可以：
     - 使用 `--use_half` 启用 FP16
     - 降低视频分辨率 `--resize_ratio 0.75`
     - 分批处理（先删除一部分，再删除另一部分）

3. **检测准确性**：
   - 文本输入可能检测到不相关的物体
   - 建议生成边界框后检查，删除不需要的边界框
   - 可以手动调整边界框位置

4. **边界框重叠**：
   - 如果多个边界框重叠，系统会合并重叠区域
   - 这是正常行为，不会影响结果

## 🎯 最佳实践

1. **先用文本输入快速定位**：
   - 输入描述，让系统自动检测
   - 查看生成的边界框列表

2. **检查并调整**：
   - 删除不需要的边界框（点击"删除"按钮）
   - 切换到手动框选模式添加遗漏的物体

3. **优化描述**：
   - 越具体的描述，检测越准确
   - 例如："红色汽车" 比 "汽车" 更准确
   - 多个物体用点号分隔："car . person"

## ❓ 常见问题

### Q: 可以删除多少个物体？

**A:** 理论上没有限制，但建议：
- 10个以内：处理速度较快
- 10-20个：可能需要较长时间
- 20个以上：建议分批处理

### Q: 文本输入检测到太多物体怎么办？

**A:** 
1. 使用更具体的描述（例如："红色汽车"而不是"汽车"）
2. 生成边界框后，在列表中删除不需要的
3. 调整 `box_threshold` 参数（提高阈值会减少检测数量）

### Q: 多个物体可以同时追踪吗？

**A:** 可以！系统会为每个边界框生成独立的掩码，然后合并处理。

### Q: 如果物体在不同帧出现怎么办？

**A:** 系统会追踪整个视频。只要物体在第一帧被框选，系统会自动追踪到后续所有帧。

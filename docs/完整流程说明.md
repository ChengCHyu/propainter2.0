## 🎯 各成员职责

### 成员A：文本定位 ⭐ 新创建

**输入**：文本描述（如"删除视频中的汽车"）  
**输出**：边界框列表 `[[x1, y1, x2, y2], ...]`  
**技术**：GroundingDINO

**使用**：
```python
from member_a import TextToBBox

module = TextToBBox()
bboxes = module.process_video_first_frame(
    video_path='video.mp4',
    text_prompt='car'  # 或 "删除视频中的汽车"
)
```

### 成员B：分割与追踪 ⭐ 已整理

**输入**：视频 + 边界框（来自成员A）  
**输出**：掩码序列（给成员C）  
**技术**：SAM + CUTIE

**使用**：
```python
from member_b import MemberBTrackAnything

module = MemberBTrackAnything()
mask_path, masks = module.process_video(
    video_path='video.mp4',
    bboxes=bboxes  # 来自成员A
)
```

### 成员C：视频修复

**输入**：视频 + 掩码（来自成员B）  
**输出**：修复后的视频  
**技术**：ProPainter

**使用**：
```bash
python inference_propainter.py -i video.mp4 -m mask_path -o results/inpainted
```

## 🚀 端到端使用示例

### Python代码方式

```python
# 1. 成员A：文本→边界框
from member_a import TextToBBox
module_a = TextToBBox()
bboxes = module_a.process_video_first_frame(
    video_path='inputs/object_removal/bmx-trees',
    text_prompt='car'  # 或 "删除视频中的汽车"
)

# 2. 成员B：边界框→掩码
from member_b import MemberBTrackAnything
module_b = MemberBTrackAnything()
mask_path, masks = module_b.process_video(
    video_path='inputs/object_removal/bmx-trees',
    bboxes=bboxes
)

# 3. 成员C：掩码→修复视频
import subprocess
subprocess.run([
    'python', 'inference_propainter.py',
    '-i', 'inputs/object_removal/bmx-trees',
    '-m', mask_path,
    '-o', 'results/inpainted'
])
```

### 命令行方式

```bash
# 步骤1：成员A - 文本→边界框
python -m member_a.text_to_bbox \
    --video inputs/object_removal/bmx-trees \
    --text "car" \
    --output results/member_a_bboxes/bboxes.json

# 步骤2：成员B - 边界框→掩码
python -m member_b.segment_track \
    --video inputs/object_removal/bmx-trees \
    --bbox results/member_a_bboxes/bboxes.json \
    --output results/member_b_masks

# 步骤3：成员C - 掩码→修复视频
python inference_propainter.py \
    -i inputs/object_removal/bmx-trees \
    -m results/member_b_masks \
    -o results/inpainted
```

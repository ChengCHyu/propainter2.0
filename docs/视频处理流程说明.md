# 视频处理流程详解

## 📋 ProPainter的输入要求

根据 `inference_propainter.py` 的代码，ProPainter需要：

1. **视频输入（二选一）**：
   - **视频文件**（.mp4, .avi, .mov等）
   - **或帧文件夹**（包含 00000.jpg, 00001.jpg 等）

2. **掩码输入（必需）**：
   - **帧文件夹**（包含 00000.png, 00001.png 等，与视频帧一一对应）

## 🔄 我们的处理流程

### 步骤1：用户上传视频
- 视频保存到：`video_object_removal_web/uploads/running_car.mp4`
- **原始视频文件保留**，不会提取成帧序列

### 步骤2：Member B 生成掩码
- Member B 使用 `_load_video()` 函数**内部读取视频帧**（使用cv2）
- 生成掩码序列，保存为PNG文件到：
  ```
  video_object_removal_web/outputs/running_car/masks/
  ├── 00000.png  (第0帧的掩码)
  ├── 00001.png  (第1帧的掩码)
  ├── 00002.png  (第2帧的掩码)
  └── ...
  ```
- **原始帧并不保存到文件系统**，只在内存中处理

### 步骤3：ProPainter修复
- 我们传递给ProPainter：
  - `-i` 参数：原始视频文件路径（如 `uploads/running_car.mp4`）
  - `-m` 参数：掩码文件夹路径（如 `outputs/running_car/masks`）
- ProPainter内部：
  - 使用 `read_frame_from_videos()` 读取视频文件（使用torchvision）
  - 使用 `read_mask()` 读取掩码文件夹中的PNG文件
  - 两者在内存中对应处理

## ✅ 关键点总结

1. **原始帧不需要保存**：
   - ProPainter可以直接从视频文件读取帧
   - 使用 `torchvision.io.read_video()` 函数
   - 代码位置：`inference_propainter.py` 第49-67行

2. **只保存掩码帧**：
   - Member B生成的掩码保存为PNG文件
   - 文件名格式：`00000.png, 00001.png, ...`
   - 必须与视频帧一一对应（按顺序）

3. **文件结构示例**：
   ```
   video_object_removal_web/
   ├── uploads/
   │   └── running_car.mp4          # 原始视频（用户上传）
   └── outputs/
       └── running_car/
           └── masks/
               ├── 00000.png        # 第0帧掩码
               ├── 00001.png        # 第1帧掩码
               └── ...
   ```

```python
def _load_video(self, video_path: str) -> List[np.ndarray]:
    """加载视频帧"""
    if video_path.endswith(('.mp4', '.avi', '.mov', '.MP4', '.AVI', '.MOV')):
        # 使用cv2读取视频
        cap = cv2.VideoCapture(video_path)
        frames = []
        while True:
            ret, frame = cap.read()
            if not ret:
                break
            frame_rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
            frames.append(frame_rgb)
        cap.release()
    else:
        # 如果是文件夹，读取帧序列
        ...
    return frames
```

# 成员A和成员B运行指南

本文档说明如何运行成员A（文本定位）和成员B（分割追踪）模块。

## 📋 目录结构

```
ProPainter/
├── member_a/              # 成员A：文本到边界框
│   ├── text_to_bbox.py    # 主程序
│   └── README.md
├── member_b/              # 成员B：分割与追踪
│   ├── member_b_track_anything.py  # 主程序
│   ├── main.py            # 命令行入口（如果存在）
│   └── README.md
└── inputs/                # 输入数据
    └── object_removal/
        └── bmx-trees/     # 示例视频帧
```

## 🚀 成员A：文本到边界框

### 功能说明
- **输入**：视频路径 + 文本描述（如"car"或"删除视频中的汽车"）
- **输出**：边界框JSON文件（给成员B使用）

### 运行方法

#### 方法1：直接运行Python文件（推荐）

```bash
# Windows PowerShell
python member_a/text_to_bbox.py --video inputs/object_removal/bmx-trees --text "car" --output results/member_a_bboxes/bboxes.json

# Windows CMD
python member_a\text_to_bbox.py --video inputs\object_removal\bmx-trees --text "car" --output results\member_a_bboxes\bboxes.json
```

#### 方法2：作为模块运行

```bash
python -m member_a.text_to_bbox --video inputs/object_removal/bmx-trees --text "car" --output results/member_a_bboxes/bboxes.json
```

### 参数说明

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `--video` | ✅ | 输入视频路径（文件或帧文件夹） | `inputs/object_removal/bmx-trees` |
| `--text` | ✅ | 文本提示 | `"car"` 或 `"删除视频中的汽车"` |
| `--output` | ❌ | 输出JSON文件路径（默认自动生成） | `results/member_a_bboxes/bboxes.json` |
| `--box_threshold` | ❌ | 边界框置信度阈值（默认0.3） | `0.3` |
| `--text_threshold` | ❌ | 文本匹配阈值（默认0.25） | `0.25` |

### 输出示例

```json
[[180, 60, 285, 181]]
```

### 注意事项

⚠️ **当前版本需要安装GroundingDINO才能使用真实检测功能**

如果没有安装GroundingDINO，模块会运行在模拟模式，返回示例边界框。

## 🎯 成员B：分割与追踪

### 功能说明
- **输入**：视频路径 + 边界框（JSON文件或JSON字符串）
- **输出**：掩码序列（PNG文件，给ProPainter使用）

### 运行方法

#### 方法1：使用 member_b_track_anything.py（推荐）

```bash
# Windows PowerShell - 使用JSON文件
python member_b/member_b_track_anything.py --video inputs/object_removal/bmx-trees --bbox results/member_a_bboxes/bboxes.json --output results/member_b_masks/bmx-trees

# Windows PowerShell - 直接使用JSON字符串
python member_b/member_b_track_anything.py --video inputs/object_removal/bmx-trees --bbox "[[180, 60, 285, 181]]" --output results/member_b_masks/bmx-trees

# Windows CMD - 使用JSON文件
python member_b\member_b_track_anything.py --video inputs\object_removal\bmx-trees --bbox results\member_a_bboxes\bboxes.json --output results\member_b_masks\bmx-trees
```

#### 方法2：使用 main.py（如果存在segment_track.py）

```bash
python member_b/main.py --video inputs/object_removal/bmx-trees --bbox "[[180, 60, 285, 181]]" --output results/member_b_masks/bmx-trees
```

### 参数说明

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `--video` | ✅ | 输入视频路径（文件或帧文件夹） | `inputs/object_removal/bmx-trees` |
| `--bbox` | ✅ | 边界框（JSON文件路径或JSON字符串） | `results/member_a_bboxes/bboxes.json` 或 `"[[180, 60, 285, 181]]"` |
| `--output` | ❌ | 输出掩码文件夹路径（默认自动生成） | `results/member_b_masks/bmx-trees` |
| `--sam_checkpoint` | ❌ | SAM模型权重路径（默认自动检测） | `weights/sam_vit_h_4b8939.pth` |
| `--tracker_checkpoint` | ❌ | 追踪器权重路径（默认自动检测） | `weights/cutie-base-mega.pth` |
| `--device` | ❌ | 设备（默认自动检测） | `cuda:0` 或 `cpu` |

### 输出说明

- 输出文件夹：`results/member_b_masks/bmx-trees/`
- 文件格式：`00000.png`, `00001.png`, `00002.png`, ...
- 掩码格式：黑白图像（0=背景，255=目标物体）

## ❓ 常见问题

### Q1: 找不到模块错误

**错误**：`ModuleNotFoundError: No module named 'member_a'`

**解决**：
1. 确保在项目根目录运行
2. 使用 `python member_a/text_to_bbox.py` 而不是 `python -m member_a.text_to_bbox`

### Q2: 成员B找不到segment_track模块

**错误**：`ModuleNotFoundError: No module named 'member_b.segment_track'`

**解决**：使用 `member_b_track_anything.py` 文件：

```bash
python member_b/member_b_track_anything.py --video ... --bbox ...
```

### Q3: 生成的掩码全是黑色

**可能原因**：
1. 边界框坐标不正确
2. SAM模型未正确加载
3. 视频第一帧读取失败

**解决**：
1. 使用 `find_bbox_tool.py` 确认边界框坐标
2. 使用 `debug_mask.py` 逐步检查
3. 检查模型文件是否存在：`weights/sam_vit_h_4b8939.pth`

### Q4: 模型文件缺失

**解决**：运行模型下载脚本：

```bash
python download_models.py
```

# 掩码问题修复说明

## 🐛 问题描述

生成的掩码全是黑色，说明掩码值不正确。

## ✅ 修复内容

### 1. 改进掩码保存逻辑

修复了 `process_video()` 方法中的掩码保存代码：

```python
# 修复前：直接保存mask（可能格式不对）
cv2.imwrite(mask_path, mask)

# 修复后：确保格式正确
mask_output = np.zeros_like(mask, dtype=np.uint8)
mask_output[mask > 0] = 255  # 非0值转为255
cv2.imwrite(mask_path, mask_output)
```

### 2. 添加调试信息

添加了第一帧掩码的统计信息，帮助诊断问题：

```python
if idx == 0:
    unique_values = np.unique(mask)
    print(f"[成员B] 第一帧掩码统计: 唯一值={unique_values}, 形状={mask.shape}, 非零像素={np.sum(mask > 0)}")
```

### 3. 改进边界框转换

改进了 `bbox_to_sam_mask()` 方法：
- 优先使用边界框直接输入（更准确）
- 如果失败，使用多个点提示
- 添加坐标验证

## 🔍 掩码格式说明

### ProPainter需要的格式

- **文件格式**：PNG图像，单通道
- **像素值**：
  - `0` = 背景（保留）
  - `255` = 前景（要删除）
- **命名**：`00000.png`, `00001.png`, ...

### 当前代码输出格式

- tracker返回：`0`=背景，`1,2,3...`=不同物体
- 代码转换：非0值 → `255`
- 最终输出：`0`=背景，`255`=前景

## 🧪 测试方法

运行代码后，检查第一帧的调试信息：

```
[成员B] 第一帧掩码统计: 唯一值=[0 1], 形状=(480, 854), 非零像素=12345
```

如果非零像素为0，说明：
1. 边界框位置不对
2. SAM分割失败
3. 需要使用 `find_bbox_tool.py` 重新确定边界框

## 💡 使用建议

1. **先确定边界框**：
   ```bash
   python member_b/find_bbox_tool.py --image video/00000.jpg --interactive
   ```

2. **使用获得的坐标运行**：
   ```bash
   python -m member_b.main --video video --bbox "[[x1,y1,x2,y2]]"
   ```

3. **检查输出**：
   - 查看第一帧掩码统计信息
   - 检查生成的PNG文件是否非空

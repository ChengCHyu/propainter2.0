## 🚀 使用方法

### 使用成员B模块

```python
from member_b import MemberBTrackAnything

module = MemberBTrackAnything()
mask_path, masks = module.process_video(
    video_path='video.mp4',
    bboxes=[[x1, y1, x2, y2]]
)
```

### 命令行使用

```bash
python -m member_b.main --video video.mp4 --bbox "[[x1,y1,x2,y2]]"
```

1. **导入路径**：使用 `from member_b import MemberBTrackAnything`
2. **文档位置**：所有文档在 `docs/` 文件夹
3. **源码位置**：成员B源码在 `member_b/` 文件夹

# 边界框（Bounding Box）格式说明

## 📐 四个数字的含义

边界框格式：`[x1, y1, x2, y2]`

### 坐标系统

```
(0,0) ──────────────→ X轴
  │
  │     ┌─────────┐
  │     │         │
  │     │  物体   │
  │     │         │
  │     └─────────┘
  │
  ↓
 Y轴
```

### 四个数字详解

```python
bbox = [x1, y1, x2, y2]
```

- **x1**: 左上角的X坐标（左边）
- **y1**: 左上角的Y坐标（上边）
- **x2**: 右下角的X坐标（右边）
- **y2**: 右下角的Y坐标（下边）

### 示例

```python
# 示例1：一个100x100的物体，位置在(100, 100)
bbox = [100, 100, 200, 200]
#        ↑    ↑    ↑    ↑
#       x1   y1   x2   y2
#       左上角     右下角
```

**可视化：**
```
图像坐标系统：
(0,0) ──────────────────────────→
  │
  │
  │        (100,100) ──── (200,100)
  │            │              │
  │            │    物体      │
  │            │              │
  │        (100,200) ──── (200,200)
  │
  ↓
```

### 实际例子

假设视频第一帧是 640x480 像素：

```python
# 示例1：删除左上角的小物体
bbox1 = [50, 50, 150, 150]
# 物体位置：从(50,50)到(150,150)，大小100x100

# 示例2：删除右下角的大物体
bbox2 = [400, 300, 600, 480]
# 物体位置：从(400,300)到(600,480)，大小200x180

# 示例3：删除中间的物体
bbox3 = [200, 150, 400, 300]
# 物体位置：从(200,150)到(400,300)，大小200x150
```

### 如何获取边界框坐标？

#### 方法1：使用图像查看工具

1. 打开视频第一帧图像
2. 查看图像尺寸（例如：640x480）
3. 用鼠标悬停在物体上，查看坐标
4. 记录物体的左上角和右下角坐标

#### 方法2：使用Python代码查看

```python
import cv2

# 读取第一帧
img = cv2.imread('inputs/object_removal/bmx-trees/00000.jpg')
h, w = img.shape[:2]
print(f"图像尺寸: {w}x{h}")

# 显示图像，用鼠标点击查看坐标
cv2.imshow('image', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

#### 方法3：使用成员A的输出（GroundingDINO）

成员A会自动检测物体并输出边界框，你直接使用即可。

### 多个物体

```python
# 删除多个物体
bboxes = [
    [100, 100, 200, 200],  # 物体1：左上角区域
    [300, 300, 400, 400],  # 物体2：右下角区域
]
```

### 注意事项

1. **坐标顺序**：必须是 `[x1, y1, x2, y2]`，不能颠倒
2. **坐标范围**：x1 < x2, y1 < y2（左上角在右下角之前）
3. **像素坐标**：坐标是像素值，从0开始
4. **第一帧**：边界框是相对于视频第一帧的坐标

### 常见错误

```python
# ❌ 错误1：坐标顺序错误
bbox = [200, 200, 100, 100]  # x2 < x1，错误！

# ❌ 错误2：超出图像范围
bbox = [0, 0, 1000, 1000]  # 如果图像只有640x480，超出范围

# ✅ 正确
bbox = [100, 100, 200, 200]  # 在图像范围内
```

## 📚 相关概念

- **像素坐标**：图像中每个像素的位置
- **边界框（Bounding Box）**：用矩形框住物体的方法
- **坐标系统**：左上角为(0,0)，向右为X轴正方向，向下为Y轴正方向

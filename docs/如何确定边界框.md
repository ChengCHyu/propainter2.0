# 如何确定准确的边界框坐标

## 🎯 问题

生成的掩码全黑，说明边界框位置不准确。

## ✅ 解决方法

### 方法1：使用可视化工具（推荐）

我已经创建了 `find_bbox_tool.py` 工具：

```powershell
# 可视化现有边界框
python find_bbox_tool.py --image inputs/object_removal/bmx-trees/00000.jpg --bbox "[150,150,250,250]"

# 交互式选择边界框（推荐）
python find_bbox_tool.py --image inputs/object_removal/bmx-trees/00000.jpg --interactive
```

### 方法2：手动查看图像

```python
import cv2
import numpy as np

# 读取第一帧
img = cv2.imread('inputs/object_removal/bmx-trees/00000.jpg')
h, w = img.shape[:2]
print(f"图像尺寸: {w}x{h}")

# 显示图像，用鼠标查看坐标
cv2.imshow('image', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 方法3：使用Python代码查看

```python
import cv2

img = cv2.imread('inputs/object_removal/bmx-trees/00000.jpg')
h, w = img.shape[:2]

# 假设要删除的是自行车（在图像中心偏左）
# 根据图像尺寸调整边界框
bbox = [w//4, h//4, w//2, h//2]  # 示例：左上1/4到中心

print(f"建议的边界框: {bbox}")
```

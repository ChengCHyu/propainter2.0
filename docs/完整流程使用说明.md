# 完整流程使用说明：物体删除

本文档说明如何使用完整流程实现视频中物体的删除。

## 📋 流程概述

完整流程包含三个步骤：

1. **成员A（可选）**：文本描述 → 边界框定位
2. **成员B**：边界框 → 掩码序列（分割与追踪）
3. **成员C**：掩码 + 视频 → 修复视频（ProPainter物体删除）

## 🚀 快速开始

### 方法1：使用文本输入（推荐）

使用文本描述自动定位物体：

```bash
# Windows PowerShell
.\run_complete_pipeline.ps1 -VideoPath "inputs/object_removal/bmx-trees" -TextPrompt "car"

# Windows CMD
run_complete_pipeline.bat --video inputs/object_removal/bmx-trees --text "car"

# Python直接运行
python complete_pipeline.py --video inputs/object_removal/bmx-trees --text "car"
```

### 方法2：使用边界框（跳过成员A）

如果已经知道边界框坐标：

```bash
# 使用边界框字符串
python complete_pipeline.py --video inputs/object_removal/bmx-trees --bbox "[[180, 60, 285, 181]]"

# 使用边界框JSON文件
python complete_pipeline.py --video inputs/object_removal/bmx-trees --bbox results/member_a_bboxes/bboxes.json
```

### 方法3：只生成掩码（跳过ProPainter）

如果只想生成掩码，不进行视频修复：

```bash
python complete_pipeline.py --video inputs/object_removal/bmx-trees --text "car" --skip-inpaint
```

## 📖 详细参数说明

### 输入参数

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `--video` | ✅ | 输入视频路径（文件或帧文件夹） | `inputs/object_removal/bmx-trees` |
| `--text` | ⚠️ | 文本提示（与--bbox二选一） | `"car"` 或 `"删除视频中的汽车"` |
| `--bbox` | ⚠️ | 边界框（与--text二选一） | `"[[180, 60, 285, 181]]"` 或 `bboxes.json` |

### 输出参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `--output` | ❌ | 输出目录 | `results/pipeline/<视频名>` |
| `--save-intermediate` | ❌ | 保存中间结果（边界框、掩码等） | 不保存 |

### ProPainter参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `--skip-inpaint` | ❌ | 跳过ProPainter修复步骤 | 不跳过 |
| `--resize-ratio` | ❌ | 视频缩放比例 | `1.0` |
| `--mask-dilation` | ❌ | 掩码膨胀像素数 | `4` |
| `--save-fps` | ❌ | 输出视频帧率 | `24` |
| `--save-frames` | ❌ | 保存输出帧 | 不保存 |
| `--fp16` | ❌ | 使用FP16精度（节省显存） | FP32 |

### 模型路径（可选）

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `--sam-checkpoint` | ❌ | SAM模型路径 | 自动检测 |
| `--tracker-checkpoint` | ❌ | 追踪器模型路径 | 自动检测 |
| `--device` | ❌ | 设备 | 自动检测 |

## 📝 使用示例

### 示例1：使用文本输入完整流程

```bash
python complete_pipeline.py \
    --video inputs/object_removal/bmx-trees \
    --text "car" \
    --output results/my_output \
    --save-intermediate
```

执行步骤：
1. 成员A：使用文本"car"在第一帧中定位汽车，生成边界框
2. 成员B：使用边界框生成掩码序列
3. 成员C：使用掩码和视频进行修复，删除汽车

输出：
- `results/my_output/bboxes.json` - 边界框（如果使用--save-intermediate）
- `results/my_output/masks/` - 掩码序列
- `results/my_output/inpainted/<视频名>/inpaint_out.mp4` - 修复后的视频

### 示例2：使用边界框跳过成员A

```bash
python complete_pipeline.py \
    --video inputs/object_removal/bmx-trees \
    --bbox "[[180, 60, 285, 181]]" \
    --output results/my_output
```

执行步骤：
1. ~~成员A~~：跳过（使用提供的边界框）
2. 成员B：使用边界框生成掩码序列
3. 成员C：使用掩码和视频进行修复

### 示例3：只生成掩码

```bash
python complete_pipeline.py \
    --video inputs/object_removal/bmx-trees \
    --text "car" \
    --skip-inpaint \
    --save-intermediate
```

执行步骤：
1. 成员A：文本到边界框
2. 成员B：边界框到掩码
3. ~~成员C~~：跳过ProPainter修复

输出：
- `results/pipeline/<视频名>/bboxes.json` - 边界框
- `results/pipeline/<视频名>/masks/` - 掩码序列

### 示例4：使用自定义参数

```bash
python complete_pipeline.py \
    --video inputs/object_removal/bmx-trees \
    --text "car" \
    --resize-ratio 0.8 \
    --mask-dilation 8 \
    --save-fps 30 \
    --save-frames \
    --fp16
```

参数说明：
- `--resize-ratio 0.8`：将视频缩放到80%大小（节省显存）
- `--mask-dilation 8`：掩码膨胀8像素（更宽的修复区域）
- `--save-fps 30`：输出视频帧率30fps
- `--save-frames`：保存输出帧（除了视频文件）
- `--fp16`：使用FP16精度（节省显存，适合GPU显存较小的情况）

## ❓ 常见问题

### Q1: 成员A检测不到物体

**可能原因**：
- 文本提示不够准确
- 视频第一帧中没有目标物体
- GroundingDINO未正确安装

**解决方法**：
1. 尝试更具体的文本提示（如"car"而不是"vehicle"）
2. 使用 `--bbox` 参数手动指定边界框
3. 使用 `member_b/find_bbox_tool.py` 交互式选择边界框

### Q2: 生成的掩码不准确

**解决方法**：
1. 使用 `member_b/debug_mask.py` 调试掩码生成过程
2. 检查边界框坐标是否正确
3. 尝试使用 `member_b/find_bbox_tool.py` 重新选择边界框

### Q3: ProPainter运行失败或显存不足

**解决方法**：
1. 使用 `--resize-ratio 0.8` 减小视频尺寸
2. 使用 `--fp16` 启用FP16精度
3. 减少 `--mask-dilation` 的值
4. 如果还是不够，可以只生成掩码（`--skip-inpaint`），然后手动运行ProPainter

### Q4: 输出视频质量不佳

**可能原因**：
- 掩码不够准确
- 物体太大或太复杂
- 视频质量本身较低

**解决方法**：
1. 检查掩码质量，确保准确覆盖目标物体
2. 调整 `--mask-dilation` 参数
3. 尝试更精确的边界框

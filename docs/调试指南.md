# 调试指南：掩码生成问题

## 🔍 问题描述

生成的掩码全是黑色（全为0），需要逐步检查每个环节。

## 🛠️ 调试工具

使用 `member_b/debug_mask.py` 脚本进行逐步调试：

```bash
python member_b/debug_mask.py --video inputs/object_removal/bmx-trees --bbox "[180,60,285,181]" --output debug_output
```

## 📊 调试步骤

脚本会逐步检查以下环节：

1. **步骤1：加载视频第一帧**
   - 检查视频是否正确加载
   - 检查图像尺寸和数据类型

2. **步骤2：验证边界框**
   - 检查边界框格式和范围
   - 可视化边界框位置

3. **步骤3：SAM分割**
   - 检查SAM是否成功分割
   - 检查掩码是否有非零像素

4. **步骤4：组合掩码**
   - 检查多个物体掩码的组合

5. **步骤5：追踪器测试（第一帧）**
   - 检查追踪器是否正常工作

6. **步骤6：追踪前5帧**
   - 检查追踪是否保持

7. **步骤7：完整流程**
   - 运行完整流程并检查结果

## 📁 输出文件

调试脚本会在 `debug_output/` 目录下生成：

- `00_first_frame.jpg` - 原始第一帧
- `01_bbox_on_frame.jpg` - 边界框可视化
- `02_sam_mask.png` - SAM分割结果
- `02_sam_mask_vis.png` - SAM掩码可视化
- `03_combined_mask.png` - 组合掩码
- `04_tracked_mask_frame0.png` - 追踪第一帧结果
- `05_tracked_frame_XX.png` - 追踪前5帧结果
- `final_masks/` - 完整流程生成的掩码

## 🐛 常见问题

### 问题1：SAM掩码全为0

**可能原因**：
- 边界框位置不对
- 边界框太小或太大
- SAM模型加载失败

**解决方法**：
1. 使用 `find_bbox_tool.py` 重新确定边界框
2. 检查边界框是否包含目标物体
3. 检查SAM模型是否正确加载

### 问题2：追踪掩码全为0

**可能原因**：
- 第一帧掩码就是全0
- 追踪器初始化失败
- 掩码格式不对

**解决方法**：
1. 先检查步骤3的SAM掩码是否正确
2. 检查追踪器是否正确初始化
3. 检查掩码格式（应该是0,1,2...的标签格式）

### 问题3：某些帧掩码丢失

**可能原因**：
- 物体移动太快
- 物体被遮挡
- 追踪器记忆不足

**解决方法**：
1. 检查视频帧率
2. 尝试在中间帧重新初始化
3. 调整追踪器参数

## 💡 使用技巧

1. **逐步检查**：从步骤1开始，逐个检查每个步骤的输出
2. **查看图像**：打开生成的图像文件，直观检查问题
3. **查看日志**：关注每个步骤的输出信息
4. **对比标准**：参考 `inputs/object_removal/bmx-trees_mask/` 中的标准掩码

## 📝 示例

```bash
# 1. 先确定边界框
python member_b/find_bbox_tool.py --image inputs/object_removal/bmx-trees/00000.jpg --interactive

# 2. 使用获得的边界框进行调试
python member_b/debug_mask.py --video inputs/object_removal/bmx-trees --bbox "[180,60,285,181]" --output debug_output

# 3. 查看输出目录中的图像文件
# 特别是 02_sam_mask.png，检查SAM是否成功分割
```
